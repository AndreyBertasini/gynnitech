# Fixture valida

## Schema

```sql
CREATE TABLE prova (id UInt32, importo Decimal(10, 2)) ENGINE = MergeTree ORDER BY id;
-- un commento con un punto e virgola; non separa le istruzioni
INSERT INTO prova SELECT number, number / 10 FROM numbers(1000);
```

## Lettura

```sql
SELECT count() AS righe FROM prova WHERE importo > 0;
```
