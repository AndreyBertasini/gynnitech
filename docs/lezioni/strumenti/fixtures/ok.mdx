# Fixture valida

## Schema

```sql
CREATE TABLE prova (id UInt32, importo Decimal(10, 2)) ENGINE = MergeTree ORDER BY id;
-- un commento con un punto e virgola; non separa le istruzioni
INSERT INTO prova SELECT number, number / 10 FROM numbers(1000);
```

## Lettura

```sql
-- Un commento davanti alla lettura non la nasconde.
SELECT count() AS righe FROM prova WHERE importo > 0;
```

## Ripetizioni ed errori attesi

```sql
-- ripeti: 3
INSERT INTO prova VALUES (1000, 1.00);

SELECT count() AS righe_dopo_la_ripetizione FROM prova;

-- ripeti: 5
-- errore atteso: UNKNOWN_TABLE
SELECT count() FROM tabella_che_non_esiste;
```
