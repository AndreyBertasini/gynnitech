# Politica i18n (IT/EN)

Il sito è in italiano. Una pagina `/en/` esiste **solo** se è la traduzione di un articolo del blog rivista da una persona.

## Pubblicare una traduzione inglese

1. Apri `src/content/blog-en/<slug-italiano>.mdx` e rivedi testo, title (≤ 60 caratteri) e description (≤ 155). Nessuna parola italiana, nemmeno nelle tabelle, nelle FAQ o nei commenti del codice.
2. Controlla `enSlug`: è lo slug pubblico inglese (`/en/blog/<enSlug>/`).
3. Nel frontmatter imposta `translationReviewed: true`, `reviewedBy: "Nome Cognome"` e `reviewedAt: "AAAA-MM-GG"`.
4. Lancia `npm run build`. Il build genera la pagina EN, gli hreflang reciproci it-IT/en-US/x-default, `/en/blog/`, `sitemap-en.xml` e il 301 dal vecchio slug italiano. Il gate `scripts/check-i18n-seo.ts` fallisce se trova testo italiano nella pagina.

Finché `translationReviewed` non è `true`, `/en/blog/<slug>/` risponde 301 verso l'articolo italiano.

## Cosa succede al resto di `/en/`

Corso, home e pagine informative in inglese erano traduzioni automatiche fatte dopo il build (gpt-4.1-mini), con `lang="it"`, `noindex` e un canonical verso l'italiano. Sono state rimosse. `scripts/write-i18n-redirects.ts` scrive in `dist/_redirects` i 301 verso le pagine italiane, con regole esplicite e un unico splat (`/en/course/*`), così nessuna regola può coprire una pagina EN reale.

## Sitemap

Le sitemap `sitemap-index.xml`, `sitemap-it.xml` e `sitemap-en.xml` sono endpoint Astro (`src/pages/sitemap-*.xml.ts`) generati dalle content collections in `src/lib/sitemap-entries.ts`. Contengono solo pagine indicizzabili (vedi `src/lib/indexability.ts`). Il lastmod viene da `dateModified`/`date` del frontmatter oppure dall'ultimo commit del file. In un clone shallow il lastmod di origine git viene omesso. `@astrojs/sitemap` è disattivato di proposito (vedi il commento in `astro.config.mjs`).

## Gate di build

`npm run build` termina con `check:i18n-seo`, che controlla quanto segue. Ogni errore fa fallire la CI.

- `lang` coerente con il prefisso dell'URL.
- Canonical uguale all'URL della pagina.
- hreflang completi, reciproci e verso pagine 200 indicizzabili.
- Assenza di italiano nelle pagine `/en/`, interfaccia compresa.
- Sitemap ↔ pagine coerenti.
- `_redirects` senza regole che coprono pagine reali e senza target inesistenti.
