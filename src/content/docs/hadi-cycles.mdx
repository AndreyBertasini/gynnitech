# HADI Cycles


Per crescere velocemente, devi imparare velocemente. Il ciclo HADI è il motore di questo apprendimento.

1. **Hypothesis**: "Se cambiamo il colore del pulsante, le conversioni aumenteranno".
2. **Action**: Implementiamo il test A/B.
3. **Data**: Raccogliamo i dati per 2 settimane.
4. **Insight**: Il pulsante rosso ha convertito il 5% in più. Implementiamo su tutto il sito.
