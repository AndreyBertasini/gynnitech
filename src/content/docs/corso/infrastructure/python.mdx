Python è il collante della tua infrastruttura dati.

## Librerie Essenziali

- **Pandas**: Per manipolazione dati in-memory (Excel con gli steroidi).
- **Requests**: Per chiamare API e scaricare dati.
- **SQLAlchemy**: Per parlare con i database.
- **Airflow/Dagster**: Per orchestrare le pipeline (ETL).
