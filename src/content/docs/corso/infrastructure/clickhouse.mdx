ClickHouse è il database analitico (OLAP) più veloce al mondo.

## Perché ClickHouse?

È colonnare. Questo significa che se chiedi la media di una colonna su un miliardo di righe, lui legge solo quella colonna, non tutto il disco.

## MergeTree

Il motore principale di ClickHouse.

```sql
CREATE TABLE visits (
    UserID UInt64,
    Country String,
    Sign Int8
) ENGINE = MergeTree()
ORDER BY UserID;
```

<Aside type="tip">
La chiave di ordinamento (`ORDER BY`) è cruciale. Definisce come i dati sono fisicamente scritti su disco e determina la velocità delle tue query.
</Aside>
