## Funzioni "Salva-Vita"

Ecco le 3 funzioni che userai nell'80% dei casi.

### 1. VLOOKUP / XLOOKUP
Unisce dati da due tabelle diverse.

```excel
=XLOOKUP(valore_ricerca; matrice_ricerca; matrice_restituita)
```

### 2. Pivot Tables
Il modo più veloce per riassumere grandi dataset.

<Card title="Scenario Tipico">
  Hai 10.000 righe di ordini. Vuoi sapere il fatturato totale per "Canale di Acquisizione".
  
  **Soluzione**: Pivot Table -> Righe: "Canale" -> Valori: "Somma di Fatturato".
</Card>

### 3. Funzioni Logiche (IF)
Per segmentare i dati al volo.

```excel
=IF(C2 > 500; "Alto Valore"; "Basso Valore")
```

## Esercizio Pratico: Calcolo del ROI

<Steps>

1.  **Prepara i dati**
    
    Crea una tabella con le colonne: `Campagna`, `Spesa (€)`, `Entrate (€)`.

2.  **Calcola il ROI**
    
    Aggiungi una colonna `ROI` con la formula:
    
    $$ \text{ROI} = \frac{\text{Entrate} - \text{Spesa}}{\text{Spesa}} \times 100 $$

3.  **Analizza**
    
    Usa la formattazione condizionale per evidenziare in **Verde** le campagne con ROI positivo e in **Rosso** quelle in perdita.

</Steps>
