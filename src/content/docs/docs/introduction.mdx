## Essentials

Everything you need to know to build great documentation.

<Steps>

1.  **Configuration**
    
    Configure your site's navigation, branding, and structure in `mint.json`.

2.  **Writing Content**
    
    Create pages using Markdown and MDX. Organize them into folders.

3.  **Components**
    
    Use built-in components like `<Card>`, `<Steps>`, and `<CodeGroup>` to make your docs interactive.

</Steps>

<Aside type="tip" title="Pro Tip">
  Mintlify automatically optimizes your images and code blocks for the best performance.
</Aside>

<Aside type="note">
  You can deploy your documentation to a custom domain on the Pro plan.
</Aside>
