Non tutti i problemi hanno un solo input. Prezzo e budget cambiano insieme. Retention e margine si muovono insieme. Appena hai piu' variabili, entri nel mondo delle funzioni multivariate.

## Mappa mentale

```mermaid

    A --> C[Funzione f(x,y)]

    B --> G[Accumulo]
```

## Integrale: il linguaggio dell'accumulo

L'integrale misura accumulo o area sotto una curva.

```text
integrale_a^b f(x) dx
```

In analytics serve per leggere:

- volume cumulato
- costo totale nel tempo
- area under curve
- valore atteso continuo

```python
import numpy as np

x = np.linspace(0, 10, 100)
y = 5 * np.exp(-0.4 * x)

area = np.trapezoid(y, x)
print(round(area, 2))
```

Questo puo' rappresentare il valore cumulato di una campagna con effetto che decade nel tempo.

### Come leggere l'integrale senza formalismi inutili

Quando una curva descrive intensita' nel tempo, l'integrale ti dice "quanto ne hai avuto in totale". In molti contesti business questa e' la domanda vera: non il picco, ma l'effetto accumulato.

## Da una variabile a due variabili

Una funzione multivariata ha questa forma:

```text
f(x, y)
```

Esempio business:

```text
revenue = f(prezzo, traffico)
```

oppure:

```text
profitto = f(sconto, costo_acquisizione)
```

## Derivata parziale

La derivata parziale misura l'effetto di una variabile tenendo ferma l'altra.

```text
df/dx
df/dy
```

Se `f(x, y)` e' profitto, `df/dx` ti dice come cambia il profitto al variare del prezzo, a budget costante.

```python
from sympy import symbols, diff

price, spend = symbols("price spend")
profit = 300 * price - 2 * price**2 + 0.8 * spend - 0.00005 * spend**2

print(diff(profit, price))
print(diff(profit, spend))
```

## Gradiente: la direzione di crescita piu' rapida

Il gradiente raccoglie tutte le derivate parziali:

```text
grad f = [df/dx, df/dy, ...]
```

In machine learning e ottimizzazione questo vettore indica come devi muoverti per aumentare o diminuire una funzione obiettivo.

```python
def grad_profit(price, spend):
    d_price = 300 - 4 * price
    d_spend = 0.8 - 0.0001 * spend
    return np.array([d_price, d_spend])

print(grad_profit(price=40, spend=5000))
```

## Dal gradiente alla decisione

Se il gradiente e' molto forte lungo una variabile e quasi piatto sull'altra, stai imparando dove intervenire prima.

Esempio:

- grande variazione rispetto a `price`, piccola rispetto a `spend`: il pricing pesa piu' del budget in quel punto
- grande variazione rispetto a `spend`, piccola rispetto a `price`: hai ancora spazio di scala sul canale

## Superficie di risposta

Per capire un problema a due variabili, spesso crei una griglia di scenari.

```python
prices = np.arange(20, 61, 10)
spends = np.arange(2000, 10001, 2000)

for p in prices:
    row = []
    for s in spends:
        profit = 300 * p - 2 * p**2 + 0.8 * s - 0.00005 * s**2
        row.append(round(profit, 1))
    print(p, row)
```

Questa tabella e' gia' pronta per una heatmap o una contour chart.

<Aside type="note">
Molte dashboard avanzate mostrano una heatmap senza dire che dietro c'e' una funzione multivariata. La matematica non e' separata dalla visualizzazione: ne e' la struttura.
</Aside>

## Collegamento diretto con AUC e probabilita'

L'area sotto una curva torna anche in statistica:

- distribuzioni di probabilita'
- ROC curve
- density estimate

Capire l'integrale qui ti semplifica meta' della probabilita' continua.

## Esempio avanzato con mini dataset reale

Il collegamento piu' utile tra integrale e machine learning e' proprio la ROC-AUC. Con il dataset `breast_cancer` puoi stimare un classificatore semplice e poi leggere l'area sotto la curva come misura sintetica della sua capacita' discriminante.

```python
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import auc, roc_curve
from sklearn.model_selection import train_test_split

data = load_breast_cancer(as_frame=True)

X_train, X_test, y_train, y_test = train_test_split(
    data.data,
    data.target,
    test_size=0.3,
    random_state=42,
    stratify=data.target,
)

model = LogisticRegression(max_iter=5000)
model.fit(X_train, y_train)

scores = model.predict_proba(X_test)[:, 1]
fpr, tpr, _ = roc_curve(y_test, scores)
auc_score = auc(fpr, tpr)

print(round(auc_score, 4))
```

Qui l'integrale non e' un passaggio astratto di analisi matematica. E' il modo con cui trasformi un'intera curva in un singolo numero difendibile.

## Errori comuni

### Leggere una relazione a due variabili come se fosse una sola

Se il profitto dipende da prezzo e spend, tenere fisso uno dei due cambia il significato della curva.

### Cercare un optimum senza vincoli

In business hai sempre limiti di budget, di inventario o di domanda.

### Scambiare il gradiente per il valore della funzione

Il gradiente dice in che direzione cambiare. Non e' il profitto stesso.

## Output atteso

Le uscite tipiche sono:

- area cumulata
- tabella scenario a due variabili
- gradient vector
- heatmap di risposta

## Riepilogo operativo

- L'integrale misura accumulo.
- Le derivate parziali separano l'effetto marginale delle singole variabili.
- Il gradiente ti dice dove la funzione cresce di piu'.
