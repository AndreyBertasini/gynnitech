Quasi mai lavori sull'intera popolazione. Lavori su un campione e speri che dica qualcosa di utile sul totale. L'inferenza statistica nasce qui.


## Popolazione, campione, parametro, statistica

- popolazione: tutti gli utenti possibili
- campione: gli utenti osservati
- parametro: valore vero della popolazione
- statistica: stima calcolata dal campione

## Il problema del campionamento

```python
import numpy as np

population = np.array([12, 14, 18, 20, 21, 25, 31, 35, 40, 55])
sample = np.random.choice(population, size=5, replace=False)

print("sample", sample)
print("sample mean", sample.mean())
print("population mean", population.mean())
```

Due campioni diversi danno stime diverse. Questa variabilita' non e' rumore inutile: e' il centro dell'inferenza.

### Il punto chiave da non perdere

Se una stima cambia da campione a campione, non significa che il metodo non funzioni. Significa che il metodo deve quantificare l'incertezza prodotta dal campionamento.

## Teorema del Limite Centrale

Il CLT dice che la distribuzione delle medie campionarie tende alla normale quando il campione cresce, anche se i dati di partenza non sono perfettamente normali.

Questo e' il motivo per cui tanti test classici funzionano.

```python
samples = []
for _ in range(5000):
    drawn = np.random.choice(population, size=5, replace=True)
    samples.append(drawn.mean())

print(round(np.mean(samples), 2), round(np.std(samples), 2))
```

## Campione grande non significa campione buono

Puoi avere un campione enorme ma distorto. Se raccogli solo utenti fortemente attivi, la precisione numerica aumenta ma la rappresentativita' resta sbagliata.

In altre parole:

- grande `n` riduce incertezza casuale
- non corregge bias di selezione

## Errore standard

L'errore standard della media e':

```text
SE = s / sqrt(n)
```

Piu' grande e' il campione, piu' stretta e' la stima.

```python
data = np.array([32, 30, 41, 27, 29, 35, 33, 38, 40, 31])
se = data.std(ddof=1) / np.sqrt(len(data))
print(round(se, 3))
```

## Intervallo di confidenza

Per una media:

```text
IC = media +- t * SE
```

```python
from scipy.stats import t

mean = data.mean()
se = data.std(ddof=1) / np.sqrt(len(data))
critical = t.ppf(0.975, df=len(data)-1)

ci_low = mean - critical * se
ci_high = mean + critical * se

print(round(ci_low, 2), round(ci_high, 2))
```

## Lettura business corretta

Se il conversion rate stimato e' 3.4% con IC 95% `[3.1%, 3.7%]`, non vuol dire che il vero valore "ha 95% di probabilita'" di stare li'. Vuol dire che la procedura produce intervalli corretti nel 95% dei campioni ripetuti.

<Aside type="caution">
Molti team leggono l'intervallo come certificazione assoluta. In realta' e' una misura di incertezza, non una promessa.
</Aside>

## Bootstrap come alternativa pratica

Se non vuoi affidarti troppo alle formule parametriche, puoi stimare l'intervallo via bootstrap.

```python
boot_means = []
for _ in range(3000):
    boot = np.random.choice(data, size=len(data), replace=True)
    boot_means.append(boot.mean())

ci_boot = np.percentile(boot_means, [2.5, 97.5])
print(np.round(ci_boot, 2))
```

## Esempio avanzato con statsmodels e mini dataset reale

Se vuoi un esempio piu' credibile di semplice bootstrap manuale, puoi prendere il dataset `diabetes` di scikit-learn e stimare un intervallo di confidenza per la progressione media della malattia in un sottogruppo ad alto BMI.

```python
from sklearn.datasets import load_diabetes
from scipy.stats import bootstrap
import numpy as np
import statsmodels.stats.api as sms

diabetes = load_diabetes(as_frame=True)
bmi = diabetes.frame["bmi"]
high_bmi_progression = diabetes.frame.loc[bmi > bmi.median(), "target"]

ci_low, ci_high = sms.DescrStatsW(high_bmi_progression).tconfint_mean()
print(round(high_bmi_progression.mean(), 2))
print((round(ci_low, 2), round(ci_high, 2)))

boot = bootstrap(
    (high_bmi_progression.to_numpy(),),
    np.mean,
    confidence_level=0.95,
    n_resamples=5000,
    random_state=42,
)

print(boot.confidence_interval)
```

Il confronto tra intervallo t-based e bootstrap ti fa vedere subito quando l'approssimazione classica e' abbastanza stabile e quando invece conviene una stima piu' robusta.

## Errori comuni

### Campione non rappresentativo

Un intervallo elegante non salva un campione distorto.

### Precisione finta

Scrivere quattro decimali non rende una stima piu' affidabile.

### Nessuna distinzione tra deviazione standard ed errore standard

La prima misura dispersione dei dati. Il secondo misura incertezza della stima.

## Output atteso

Le uscite tipiche sono:

- media campionaria
- errore standard
- intervallo di confidenza
- confronto tra stima e popolazione nota o target

## Riepilogo operativo

- Il campione introduce incertezza strutturale.
- Il CLT spiega perche' le medie campionarie diventano trattabili.
- Gli intervalli di confidenza servono a mostrare ampiezza dell'incertezza, non a nasconderla.
