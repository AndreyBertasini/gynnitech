# SEO e Content Analytics


Il traffico organico è il canale di acquisizione più sostenibile a lungo termine.


## Le 3 Dimensioni della SEO Analytics


### 1. Technical SEO

- **Core Web Vitals:** LCP (< 2.5s), FID (< 100ms), CLS (< 0.1)
- **Indexing:** Le pagine importanti sono indicizzate? (Google Search Console)
- **Crawl budget:** Google riesce a scansionare il tuo sito efficacemente?

### 2. Content Performance

- **Traffico organico per pagina:** Quali contenuti portano visite?
- **Average Position:** A che posizione media appari su Google?
- **CTR dalla SERP:** Quanti cliccano sul tuo risultato vs la posizione media?
- **Dwell Time:** Quanto tempo restano sulla pagina? (segnale di qualità)

### 3. Keyword Analytics

- **Search Volume:** Quante persone cercano questa keyword al mese?
- **Keyword Difficulty:** Quanto è difficile posizionarsi?
- **Search Intent:** L'utente vuole informarsi, comprare, o navigare?

## Content Audit


Analisi periodica (ogni 6 mesi) di tutto il contenuto:


| Azione     | Criterio                                             |
| ---------- | ---------------------------------------------------- |
| **Keep**   | Traffico alto, ancora rilevante                      |
| **Update** | Traffico in calo, ma l'argomento è ancora valido     |
| **Merge**  | Più articoli sullo stesso topic → Consolida in uno   |
| **Delete** | Nessun traffico, nessun backlink, contenuto obsoleto |


## Strumenti Essenziali

- **Google Search Console:** Gratuito, dati ufficiali di Google
- **Ahrefs / SEMrush:** Keyword research, backlink analysis, competitor analysis
- **Screaming Frog:** Audit tecnico del sito
- **Google Analytics 4:** Comportamento utente post-click
