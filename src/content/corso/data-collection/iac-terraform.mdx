# Infrastructure as Code con Terraform


## Perché IaC per Data Infrastructure


| Problema Manuale                         | Soluzione Terraform                        |
| ---------------------------------------- | ------------------------------------------ |
| "Chi ha cambiato quella configurazione?" | Git history di ogni modifica               |
| "Ricreare l'ambiente di staging"         | `terraform apply` e hai una copia identica |
| "Quanto costa questa infrastruttura?"    | `terraform plan` mostra le risorse         |
| "Documentazione obsoleta"                | Il codice È la documentazione              |
| "Errore umano nel deploy"                | Review del piano prima dell'apply          |


## Concetti Fondamentali


### Provider, Resource, State


```plain text
# Provider: connessione al cloud
provider "aws" {
  region = "eu-west-1"
}

# Resource: un'entità infrastrutturale
resource "aws_s3_bucket" "data_lake" {
  bucket = "marketing-data-lake-prod"

  tags = {
    Environment = "production"
    Team        = "data-engineering"
  }
}

# Data source: legge dati esistenti
data "aws_vpc" "main" {
  default = true
}
```


### Workflow Terraform


```plain text
terraform init     → Scarica i provider e inizializza
terraform plan     → Mostra cosa verrà creato/modificato/eliminato
terraform apply    → Applica le modifiche (con conferma)
terraform destroy  → Elimina tutte le risorse (con conferma)
```


## Provisioning dello Stack Dati


### S3 Data Lake


```plain text
# S3 Bucket con lifecycle policy
resource "aws_s3_bucket" "marketing_data_lake" {
  bucket = "marketing-data-lake-${var.environment}"

  tags = {
    Environment = var.environment
    Team        = "data-engineering"
    ManagedBy   = "terraform"
  }
}

resource "aws_s3_bucket_versioning" "marketing_data_lake" {
  bucket = aws_s3_bucket.marketing_data_lake.id
  versioning_configuration {
    status = "Enabled"
  }
}

resource "aws_s3_bucket_lifecycle_configuration" "marketing_data_lake" {
  bucket = aws_s3_bucket.marketing_data_lake.id

  rule {
    id     = "marketing-events-lifecycle"
    status = "Enabled"

    filter {
      prefix = "events/"
    }

    transition {
      days          = 30
      storage_class = "STANDARD_IA"
    }

    transition {
      days          = 180
      storage_class = "GLACIER"
    }

    expiration {
      days = 730
    }
  }
}

resource "aws_s3_bucket_server_side_encryption_configuration" "marketing_data_lake" {
  bucket = aws_s3_bucket.marketing_data_lake.id

  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm = "AES256"
    }
  }
}
```


### Kafka (Confluent Cloud)


```plain text
provider "confluent" {
  cloud_api_key    = var.confluent_api_key
  cloud_api_secret = var.confluent_api_secret
}

resource "confluent_environment" "marketing" {
  display_name = "marketing-${var.environment}"
}

resource "confluent_kafka_cluster" "main" {
  display_name = "marketing-analytics"
  availability = "MULTI_ZONE"
  cloud        = "AWS"
  region       = "eu-west-1"

  standard {}

  environment {
    id = confluent_environment.marketing.id
  }
}

resource "confluent_kafka_topic" "marketing_events" {
  kafka_cluster {
    id = confluent_kafka_cluster.main.id
  }

  topic_name       = "marketing.events"
  partitions_count = 12

  config = {
    "retention.ms"    = "604800000"  # 7 giorni
    "cleanup.policy"  = "delete"
    "compression.type" = "zstd"
  }

  rest_endpoint = confluent_kafka_cluster.main.rest_endpoint
}
```

## CI/CD per Infrastructure


### GitHub Actions Workflow


```yaml
# .github/workflows/terraform.yml
name: Terraform

on:
  pull_request:
    paths: ['infrastructure/**']
  push:
    branches: [main]
    paths: ['infrastructure/**']

jobs:
  terraform:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: infrastructure/environments/prod

    steps:
      - uses: actions/checkout@v4

      - uses: hashicorp/setup-terraform@v3
        with:
          terraform_version: 1.7.0

      - name: Terraform Init
        run: terraform init

      - name: Terraform Format Check
        run: terraform fmt -check -recursive

      - name: Terraform Plan
        run: terraform plan -out=tfplan
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}

      - name: Terraform Apply
        if: github.ref == 'refs/heads/main'
        run: terraform apply -auto-approve tfplan
```

## Alternative a Terraform


| Strumento      | Linguaggio   | Pro                                  | Contro                       |
| -------------- | ------------ | ------------------------------------ | ---------------------------- |
| **Terraform**  | HCL          | Standard de facto, enorme ecosistema | HCL non è un vero linguaggio |
| **Pulumi**     | Python/TS/Go | Linguaggi veri, testing nativo       | Meno provider disponibili    |
| **AWS CDK**    | Python/TS    | Integrato con AWS, type safety       | Solo AWS                     |
| **Crossplane** | YAML/K8s     | GitOps nativo, Kubernetes-based      | Curva di apprendimento       |
