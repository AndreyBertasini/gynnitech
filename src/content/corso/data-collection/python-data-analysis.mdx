# Python per Data Analysis


Python è il linguaggio dominante per l'analisi dei dati. Con 3 librerie puoi fare il 90% del lavoro.


## Pandas — Manipolazione Dati


### Leggere i dati


```python
import pandas as pd

# Da CSV
df = pd.read_csv('marketing_data.csv')

# Da database
from sqlalchemy import create_engine
engine = create_engine('clickhouse://localhost/marketing')
df = pd.read_sql('SELECT * FROM campaigns', engine)

# Prime righe
df.head()
df.info()   # Tipi, missing values
df.describe()  # Statistiche base
```


### Filtrare e aggregare


```python
# Filtra campagne con spesa > 1000€
big_campaigns = df[df['spend'] > 1000]

# Raggruppa per canale
channel_perf = df.groupby('channel').agg({
    'spend': 'sum',
    'conversions': 'sum',
    'revenue': 'sum'
}).reset_index()

# Calcola CPA e ROAS
channel_perf['cpa'] = channel_perf['spend'] / channel_perf['conversions']
channel_perf['roas'] = channel_perf['revenue'] / channel_perf['spend']
```


### Pulizia dati


```python
# Rimuovi duplicati
df = df.drop_duplicates(subset=['transaction_id'])

# Gestisci missing values
df['channel'] = df['channel'].fillna('direct')
df['revenue'] = df['revenue'].fillna(0)

# Converti tipi
df['date'] = pd.to_datetime(df['date'])
```


## NumPy — Calcoli Numerici

## Matplotlib e Seaborn — Visualizzazione


```python
import matplotlib.pyplot as plt
import seaborn as sns

# Line chart: trend nel tempo
fig, ax = plt.subplots(figsize=(12, 6))
ax.plot(df['date'], df['revenue'], label='Revenue')
ax.plot(df['date'], df['spend'], label='Spend')
ax.set_title('Revenue vs Spend nel Tempo')
ax.legend()
plt.show()

# Bar chart: performance per canale
sns.barplot(data=channel_perf, x='channel', y='roas')
plt.title('ROAS per Canale')
plt.show()

# Heatmap: correlazione
sns.heatmap(df[['spend', 'clicks', 'conversions', 'revenue']].corr(),
            annot=True, cmap='coolwarm')
plt.title('Matrice di Correlazione')
plt.show()
```


## Caso Pratico: Analisi Campagne


```python
# 1. Carica dati
df = pd.read_csv('campaigns_2025.csv')

# 2. Calcola metriche
df['ctr'] = df['clicks'] / df['impressions']
df['cpa'] = df['spend'] / df['conversions']
df['roas'] = df['revenue'] / df['spend']

# 3. Trova le campagne migliori
top_campaigns = df.nlargest(10, 'roas')

# 4. Segmenta per performance
df['performance'] = pd.cut(df['roas'],
    bins=[0, 1, 3, float('inf')],
    labels=['Perdita', 'OK', 'Eccellente'])

# 5. Report
report = df.groupby('performance').agg({
    'spend': 'sum',
    'revenue': 'sum',
    'campaign_name': 'count'
}).rename(columns={'campaign_name': 'n_campaigns'})
print(report)
```
