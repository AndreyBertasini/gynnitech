# Piano di Replicazione Mintlify con Astro

Questo piano trasformerà l'attuale progetto in un clone completo del sito web di Mintlify, integrando una landing page di marketing personalizzata ad alte prestazioni con una sezione di documentazione basata su Starlight.

## 1. Configurazione dell'Ambiente e Dipendenze
Per supportare componenti interattivi avanzati e animazioni fluide come nel sito originale:
- [ ] Installare l'integrazione **React** per Astro (`@astrojs/react`).
- [ ] Installare **Framer Motion** per gestire le animazioni e transizioni complesse.
- [ ] Installare **Lucide React** per il set di icone richiesto.
- [ ] Aggiungere utility per le classi CSS (`clsx`, `tailwind-merge`).

## 2. Design System e Stili Globali
Definire l'identità visiva per replicare il look "Dark & Mint" di Mintlify:
- [ ] Configurare **Tailwind CSS** con la palette colori specifica (sfondi scuri, accenti verde menta, gradienti sottili).
- [ ] Impostare la tipografia (Inter/Geist) per corrispondere al sito originale.
- [ ] Creare un layout base (`Layout.astro`) per le pagine di marketing (Home, Pricing, ecc.) separato dal layout della documentazione.

## 3. Sviluppo Componenti UI (Marketing)
Creare i blocchi costruttivi della landing page clonando il design di Mintlify:
- [ ] **Navbar**: Header responsive e sticky con logo, menu a discesa, e pulsanti CTA (Login/Get Started).
- [ ] **Hero Section**: Titolo impattante, sottotitolo, pulsanti e l'elemento visivo caratteristico (preview del codice o grafica astratta).
- [ ] **Feature Grid**: Griglia di card con icone Lucide che evidenziano le funzionalità (es. "MDX Support", "Analytics").
- [ ] **Interactive Elements**: Eventuali tab o slider per mostrare esempi di codice/funzionalità.
- [ ] **Footer**: Struttura a colonne con link e copyright.

## 4. Implementazione delle Pagine
- [ ] **Landing Page (`src/pages/index.astro`)**: Sviluppare la home page completa assemblando i componenti creati, assicurando la fedeltà al design originale.
- [ ] **Integrazione Documentazione**: Mantenere e configurare **Starlight** per gestire la rotta `/docs`, stilizzandola per essere coerente con il resto del sito (replicando l'esperienza "Docs" di Mintlify).

## 5. Rifinitura e Ottimizzazione
- [ ] **Animazioni**: Applicare animazioni di entrata (fade-in, slide-up) agli elementi della home page.
- [ ] **Responsività**: Verificare e correggere il layout su mobile e tablet.
- [ ] **SEO & Performance**: Ottimizzare i meta tag e assicurare il caricamento rapido delle risorse.
